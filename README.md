# rabotaNW

Счётчик прогресса по работе. Норма на день, выходные и излишек за месяц.

Сайт: https://nephwf.github.io/rabotaNW/

Структура как у kaloriiNW: `index.html`, `app.js`, `styles.css`, `manifest.json`, `sw.js`, иконки.

## Установка

Кнопка «Установить на телефон». На Android ставит приложение, на iPhone показывает «Поделиться» → «На экран Домой».

## Подсчёт

- Число идёт в сумму. «-» — выходной и не входит в план. Пусто — день ещё открыт.
- Пока есть пустые дни: `Пров. в день`.
- Когда все дни закрыты: `Излишек за месяц` = сумма − (дни в зачёте × норма).
