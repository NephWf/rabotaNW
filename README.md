# rabotaNW

Сайт для подсчёта прогресса по работе.

Норма на день (по умолчанию 200). «-» — выходной и не входит в план. Пустая ячейка — день ещё не закрыт.

- Пока есть пустые дни: `Пров. в день` — сколько нужно делать в каждый оставшийся день, чтобы закрыть план.
- Когда все дни закрыты: `Излишек за месяц` = сумма − (дни в зачёте × норма).

Сайт после включения Pages: https://nephwf.github.io/rabotaNW/

Чтобы опубликовать: Settings → Pages → Branch `main` / folder `/ (root)` → Save.

Данные хранятся в браузере. JSON можно скачать и загрузить обратно.
